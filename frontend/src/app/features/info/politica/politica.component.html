Política de devoluciones

Cambios

Cambios únicamente por TALLE o FALLA de fábrica, si NO hay stock no se realizan cambios por otro modelo o color

Se realiza el cambio UNA sola vez, dentro de los 7 días después de realizada la compra.

No se aceptan prendas con perfume, lavadas, usadas o maltratadas.

Las ofertas no tienen cambios ni devoluciones.
